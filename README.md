# CET-6 真题自学网站

2019.06–2026.06 共 18 个批次 52 套真题的纯静态自学站点，部署于 GitHub Pages。

**在线访问**：https://jlshdsdk.github.io/cet6/

## 功能

- 按年份批次组织的全部 52 套真题（MPA，每套一个自包含页面，零构建零依赖）
- 听力：站内音频（48kbps 单声道）、逐段原文、默认折叠的中文译文、倍速播放、断点续听
- 阅读：选词填空 / 匹配 / 仔细阅读全部段落逐段配译文，可一键隐藏全部译文
- 写作与翻译：范文、参考译文、审题要点；答案速查 + 每题解析
- 点词查询：内置离线词典（ECDICT 精简 3.2 万词，按首字母懒加载），点击任意英文单词秒出释义
- 生词本：收藏、来源标注、遮释义自测、导出/导入 JSON（跨设备迁移）
- 做题进度：未开始 / 做题中 / 已核对，首页总览

## 目录

```
index.html          首页（年份导航 + 进度）
exam/{yyyymm}/      每套卷页面
writing/            作文句型、翻译热词、预测
vocab.html          生词本
assets/             全站唯一样式与脚本
dict/               离线词典分片
audio/              压缩听力音频
```

数据流水线与完整规格见 `_build/`（不入库）与项目 PROMPT。
